## 2024-06-10 - Pattern of Missing ARIA Labels on Icon-Only Quick Actions
**Learning:** Many icon-only buttons (like Add to Cart, Add to Wishlist, Quick View) within hover-revealed product cards across the application (e.g., RelatedProducts.jsx, NotificationCenter.jsx, QuickBuySection.jsx) are missing explicit `aria-label`s, rendering them completely inaccessible to screen reader users. Additionally, hover-revealed quick action containers often lack `focus-within:opacity-100` styling, meaning keyboard users tab into invisible interactive elements, creating hidden focus traps.
**Action:** When implementing or updating hover-based product quick actions, always ensure (1) a descriptive `aria-label` or `title` is provided for each icon-only button, (2) `focus-within:opacity-100` (or similar) is added to the parent overlay so it becomes visible on keyboard focus, and (3) buttons have explicit `focus-visible` styling (e.g., `focus-visible:ring-2 focus-visible:outline-none`) to clearly indicate keyboard interaction.
